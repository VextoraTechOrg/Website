## 1. Generation instructions (for the AI)

### Goal
Create a **client-facing company profile deck** for VextoraTech — suitable for intros, proposals, and first meetings. Not a pitch for investors; tone is engineering partner, not startup hype.

### Output preferences (pick what the tool supports)
1. **Preferred:** A downloadable `.pptx` file.
2. **Fallback:** Slide-by-slide outline with exact titles, bullet copy, speaker notes, and layout notes — ready to paste into PowerPoint / Google Slides / Gamma.

- Prefer real product names and tech stacks from this brief over generic filler.
- Include a closing CTA slide with contact details.

### Domain strengths (lead with these)
- **Computer Vision** — Object detection, OCR, ANPR, face recognition, multi-camera surveillance.
- **Voice AI** — Whisper transcription, diarization, call analytics.
- **RAG & LLM Systems** — Grounded assistants with vector search, citations, guardrails.
- **Full-Stack Products** — React + FastAPI platforms from prototype through launch.

### Engagement models
- **Fixed-scope build** — Defined MVP/features, deliverables, acceptance criteria.
- **Ongoing product partnership** — Retained team embedded in the roadmap.
- **Discovery / PoC** — Short spike to validate feasibility before a full build.

### Delivery process (4 steps)
1. **Discovery** — Goals, constraints, scope, success metrics.
2. **Design** — Wireframes and Figma prototypes before heavy code.
3. **Build** — Agile sprints, weekly demos, real deploys early.
4. **Launch & scale** — Production rollout, monitoring, ongoing support.
